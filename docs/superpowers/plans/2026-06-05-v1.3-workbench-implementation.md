# NewCar V1.3 Workbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the V1.3 evidence-driven purchase due-diligence workflow from the PRD and interaction design.

**Architecture:** Keep the current static frontend and local Node service architecture, but tighten boundaries through testable pure helpers in `app.js` and `scripts/quality-safety.mjs`. The first implementation pass focuses on P0 user-visible flows: consolidated navigation, discovery split, candidate investigation layout, quality evidence states, information wall confirmation, redline gate, and AI task status clarity.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Node.js built-in test runner, local `.mjs` service scripts.
