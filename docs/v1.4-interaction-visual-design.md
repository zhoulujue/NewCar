# NewCar V1.4 交互与视觉设计文档

更新日期：2026-06-05

## 1. 设计原则

V1.4 的核心不是把页面做得更“满”，而是把已经存在的证据、风险和质量判断转成可操作的沟通工具。

设计关键词：

- **行动优先**：每个风险都要落到下一步动作。
- **分层可信**：区分官方数据、第三方数据、车主口碑和单车证明。
- **可复制**：真实购车沟通主要发生在微信、电话和线下看车，清单必须可以复制。
- **移动现场友好**：手机端优先支持快速读、快速复制、快速上传。
- **克制专业**：保留当前工作台气质，不做资讯站或营销页。

## 2. 信息架构调整

候选详情页保留现有结构：

1. 车辆概览
2. 决策报告
3. 真实成本
4. 质量与三电
5. 信息墙
6. 决策记录
7. 右侧决策 rail：红线、风险、工作流、下一步

新增：

> 取证行动台：放在“质量与三电”之后、“价格时间线”之前。

理由：
- 用户先看到质量和三电证据是否完整，再立刻看到应该如何取证。
- 它不是一个孤立工具，而是连接质量、风险、商家、检测和合同的执行层。

## 3. 取证行动台交互设计

### 3.1 面板结构

标题区：
- 标题：取证行动台
- 副标题：把缺失证据转成问商家、问检测机构和合同备注
- 主按钮：复制取证包

内容区分为四块：

1. 决策状态卡
   - 取证就绪度
   - 当前门槛：先别付款 / 继续取证 / 可约复检 / 可谈价
   - 核心说明
   - 关键阻断项

2. 问商家清单
   - 用自然语言展示 5-8 个问题
   - 可单独复制

3. 检测机构清单
   - 侧重 SOH、故障码、电池一致性、底盘电池包、结构件、维保
   - 可单独复制

4. 合同备注
   - 侧重承诺留痕、复检不过处理、三电质保、智驾权益、费用、退订
   - 可单独复制

底部：
- 下一步顺序：3-5 个步骤，按优先级排列。

### 3.2 状态规则

#### 先别付款

触发：
- 存在高风险红线未关闭。
- 二手车缺 SOH、维保、故障码、三电质保中的 3 项及以上。
- 三电风险为高。

界面：
- 暖红/橙色边框。
- 文案明确：“只适合继续要材料或排除，不建议交大额定金。”

#### 继续取证

触发：
- 有明显缺口，但不全是高风险。
- 关键材料不足，暂不适合进入谈价。

界面：
- 温和琥珀色。
- 强调“先把材料拿到，再谈价格”。

#### 可约复检

触发：
- 基础证据达到一定比例，仍需第三方检查。
- 高风险红线较少或可通过复检解释。

界面：
- 蓝绿色。
- 强调“复检结果决定是否谈价”。

#### 可谈价

触发：
- 证据较完整，风险可量化。
- 价格仍高于目标，或风险可以作为价格安全垫。

界面：
- 绿色。
- 强调“带着清单和合同条款谈”。

## 4. 视觉设计

### 4.1 桌面端

布局：
- 面板内部使用 12 栅格感觉的响应式网格。
- 决策状态卡横跨整行。
- 三个清单卡在桌面端三列排列，窄屏自动两列/一列。

视觉：
- 取证就绪度使用大数字，不做仪表盘，避免视觉噪音。
- 清单卡使用浅底色和明确标题，按钮靠右上或底部。
- 阻断项使用短标签，不堆长段落。

### 4.2 手机端

布局：
- 单列卡片。
- 复制按钮全宽。
- 清单内容使用紧凑编号列表。
- 面板间距比桌面更紧，但保留触控高度。

交互：
- 点击复制后 toast 告知“已复制问商家清单/检测清单/合同备注”。
- 不在清单卡里使用复杂表格。

### 4.3 文案风格

避免：
- “建议谨慎”“请注意风险”这种空话。

采用：
- “先向商家要 SOH/维保/质保截图，拿不到就不要交大额定金。”
- “复检时要求读取 OBD 故障码、电池一致性/压差，并让检测机构写入报告。”
- “合同备注写明：若复检发现结构件/电池包维修或三电质保不随车，订金原路退回。”

## 5. 本次实现验收

功能验收：
- 每台候选详情页都有“取证行动台”。
- 一键复制完整取证包可用。
- 三个分组清单可单独复制。
- 二手车缺少三电证据时，行动台必须生成明确问题。
- 新车也能生成首批质量、召回、试驾和权益观察清单。

视觉验收：
- 桌面端不压缩、不溢出、不和右侧 rail 冲突。
- 手机端单列展示，按钮不挤压文字。
- 和现有 NewCar 的深色导航、浅色工作台、圆角 8px 以内卡片风格一致。

技术验收：
- 新增静态测试覆盖结构、关键函数、复制入口和 CSS 类。
- `node --test scripts/tests/*.test.mjs` 通过。
- `node --check app.js` 通过。
- 本地浏览器打开详情页无控制台错误。
